# Milestone 001: Repository Foundation

## Goal

Create a clean source repository for JARVIS OS before implementing runtime behavior.

## Scope

Included:

```text
README
architecture documentation
security documentation
protocol documentation
development runbook
roadmap
initial source directories
artifact ignore rules
```

Excluded:

```text
runtime code
AI provider calls
terminal execution
system mutation tools
ISO rebuilds
package installation
service installation
```

## Acceptance Criteria

- Repository structure exists.
- Architecture is documented.
- Security model is documented.
- Tool protocol is documented.
- Development runbook explains local safety boundaries.
- ISO artifacts and secrets are ignored.
- No destructive host changes are made.

## Next Milestone

Milestone 002 should introduce core protocol schemas and a minimal test harness.
