# JARVIS Desktop Product Notes

The JARVIS Desktop should be AI-first while still exposing deterministic system controls.

## Required Areas

```text
Home
AI Assistant
Terminal
System Monitor
Processes
Services
Files
Network
Security
Recovery
Settings
```

## Product Direction

The interface should expose what JARVIS knows, what it is doing, what it is allowed to do, and what needs authorization.

Users should be able to inspect tool calls, audit history, recovery plans, verification results, and rollback status.

## Deferred Work

Desktop implementation begins after the core runtime, tools, policy engine, memory, monitoring, diagnostics, and recovery foundations exist.
